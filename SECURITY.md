# Security policy

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for `attributionkit/attribution` and include affected version, impact, reproduction, and any proposed remediation.

Never include live provider credentials, App Store Connect private keys, postback payloads, or customer data in a report. Sanitized fixtures are welcome.

Supported security fixes are issued for the latest minor release. The runtime deliberately contains no identifier APIs or network client; changes to that boundary require explicit security review.
